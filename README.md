# Viha Srinivas — personal website

A colorful editorial portfolio for [vihasrin.github.io](https://vihasrin.github.io/), inspired by the free composition and typography of Readymag. Built with HTML, CSS, and JavaScript. No build step, framework, or package installation is required.

## Run locally

From this repository, run `python3 -m http.server 4173` and visit `http://localhost:4173`.

## Publish with GitHub Pages

The website files are at the repository root. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. The `.nojekyll` file lets GitHub serve these files directly. Once deployment completes, the site will be available at [https://vihasrin.github.io/](https://vihasrin.github.io/).

## Edit the site

- `index.html`: biography, contact links, work cards, notebook, and search/social metadata.
- `styles.css`: responsive layout, colors, typography, and motion preferences.
- `script.js`: project details, work filters, notebook rearrangement, and email copying.
- `assets/`: portrait, favicon, social image, and locally hosted fonts.

The project thumbnails are custom illustrations, rather than screenshots of the original projects. Project detail dialogs link to verified public sources. They intentionally avoid inventing project outcomes or unpublished internship details.

The site works without JavaScript: all content and navigation remain available, project cards open their public sources, and email links work. JavaScript adds progressively enhanced filters and dialogs. Reduced motion settings are respected, and dialogs support keyboard navigation and Escape.
